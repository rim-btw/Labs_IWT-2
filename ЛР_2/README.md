# Лабораторная работа 2: Построение бинарного дерева (Рекурсивный подход)

## Задание
Написать на языке Python **рекурсивную** функцию `gen_bin_tree`, которая строит бинарное дерево. 
Результат должен представлять собой словарь с ключами `value`, `left`, `right`. 
Алгоритмы вычисления левого и правого потомка по умолчанию должны быть заданы с помощью `lambda`-функций.

## Вариант
Мой номер в группе: **2**.
Параметры варианта:
- `root` = 2
- `height` = 6
- `left_leaf` = `root * 3`
- `right_leaf` = `root + 4`

## Реализация
Функция `gen_bin_tree` реализована в файле `bin_tree.py`.
Используется **рекурсивный** алгоритм: функция вызывает саму себя для создания левого и правого поддеревьев, пока высота `height` не станет равна 0 (базовый случай рекурсии).

## Типизация и документация
- Использованы аннотации типов (`typing.Callable`, `Optional`, `Union`).
- Написана документация по стандарту **PEP 257** (docstrings для функции и тестов).

## Тестирование
Тесты реализованы с использованием модуля `unittest` в отдельном файле `test_bin_tree.py`.
Проверяются:
1. Значения по умолчанию (согласно варианту 2).
2. Работа с кастомными лямбда-функциями.
3. Граничные случаи (`height = 0` и `height < 0`).
