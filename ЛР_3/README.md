# Лабораторная работа 3: Построение бинарного дерева

## Задание
Написать на языке Python **нерекурсивную** функцию `gen_bin_tree`, которая строит бинарное дерево. 
Результат должен представлять собой словарь с ключами `value`, `left`, `right`. 
Алгоритмы вычисления левого и правого потомка по умолчанию должны быть заданы с помощью `lambda`-функций.

## Вариант
Мой номер в группе: **2**.
Параметры варианта:
- `root` = 2
- `height` = 6
- `left_leaf` = `root * 3`
- `right_leaf` = `root + 4`

## Реализация
Функция `gen_bin_tree` реализована в файле `binary_tree.py`.
Для выполнения требования **нерекурсивности** используется алгоритм обхода в ширину (BFS) с применением структуры данных `collections.deque` (двусторонняя очередь). 
Очередь хранит пары: `(узел, текущий_уровень)`. Мы извлекаем узел, создаем его потомков, привязываем их к текущему узлу и добавляем в очередь, пока не достигнем заданной высоты `height`.

## Типизация и документация
- Использованы аннотации типов (`typing.Callable`, `Optional`, `Union`).
- Написана документация по стандарту **PEP 257** (docstrings для функции и тестов).

## Тестирование
Тесты реализованы с использованием модуля `unittest` в отдельном файле `test_binary_tree.py`.
Проверяются:
1. Значения по умолчанию (согласно варианту 2).
2. Работа с кастомными лямбда-функциями.
3. Граничные случаи (`height = 0` и `height < 0`).
